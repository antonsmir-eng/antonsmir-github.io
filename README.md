# Антон Смирнов — CFO-as-a-Service

Премиальный сайт услуг финансового директора на аутсорсе.

**Сайт:** https://antonsmir-eng.github.io/antonsmir-github.io/

## Экспертиза

- ликвидность и казначейство;
- управленческий учёт и FP&A;
- долг и рефинансирование;
- финансовые модели, инвестиции и M&A;
- автоматизация финансовой функции.

Сайт автоматически публикуется через GitHub Pages после обновления ветки `main`.
