# Переделка StreetArt

## Scope
Главная, общая навигация, каталог, калькулятор, кейсы и общие шаблоны. Persuade для главной; Operate для калькулятора и адресной программы; Read для статей. Продуктовые функции и факты сохраняются.

## Direction contract
THESIS: масштаб печати через крупный набор и реальную фотографию, затем быстрый расчёт. Услуги представлены строками, без декоративной нумерации и повторяющихся коробок.

OWN-WORLD: фирменный чернильный, оранжевый, светлая бумага; прямые края, спокойные формы. Локальный нейтральный DejaVu Sans как разрешённая замена отсутствующему Akrobat. Заголовок до 96 px, читаемый основной текст 16–18 px.

STORY: посетитель понимает, что можно напечатать, видит предварительную цену, затем выбирает подробный расчёт. Кейсы и контроль качества поддерживают доверие без придуманных фактов.

FIRST VIEWPORT: крупный заголовок слева, печатный станок справа; под ними одна широкая панель расчёта с материалом, размерами, тиражом и итогом. На мобильном текст, компактная фотография, затем расчёт.

FORM: фирменный печатный лист. Кодовая реализация по существующему ТЗ. Дополнительный движок и concept-seed недоступны: автоматическая проверка отклонила скачивание, поэтому применяется разрешённая локальная альтернатива. Установленный навык не меняет разрешения пользователя.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
