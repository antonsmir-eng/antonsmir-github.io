# StreetArt — сайт и личный кабинет

Редакция 2026-10-05. Минимальный заказ — **15 000 ₽ с НДС**. Добавлены регистрация по почте, серверные заявки, история заказов, административное управление и адаптер оплаты. Внешняя CRM и аналитика не подключены. Доступ остаётся приватным.

## Возможности

- Главная, каталог 28 типов и 334 исполнений, 13 групп материалов; прежние страницы продуктов сохранены.
- Шесть сценариев: наружные форматы, печать по площади, конструктор, полиграфия, адресная программа, подбор материала.
- Построчная смета, НДС, PDF/Excel, параметры в ссылке.
- Локальные проекты: сохранение, продолжение, JSON, удаление с отменой.
- Пошаговый бриф: изделие, объект, документы; автосохранение и готовый JSON.
- XLSX/CSV адресной программы: ошибки, изделия, отправления, упаковка, вес и выезды.
- Проверка доступных параметров макета, кейсы, отрасли, база знаний.
- Импорт/экспорт прайса JSON на устройстве. Это не изменение общего прайса.
- Светлая и тёмная темы, адаптивность от 320 px.

Кабинет на `/account` хранит пользователей, заказы, сметы, историю и платежи в D1; прикреплённые файлы — в R2. Клиент видит только свои заказы, администратор — все. Начальный вход `admin` / `admin` требует смены пароля. Счёт доступен после заполнения реквизитов; онлайн-оплата — после настройки магазина ЮKassa. Подробности и границы запуска: [CABINET.md](CABINET.md).

Локальные расчёты на `/projects` и старый бриф сохраняются на устройстве. Их JSON и метаданные файлов отличаются от серверных заказов. Калькулятор умеет перенести параметры в новую заявку кабинета.

## Минимальный заказ

data/prices.json → minimumOrderTotal:15000 задаёт минимум с НДС. Функция orderEligibility в lib/pricing.ts сравнивает стоимость известных работ с НДС независимо от переключателя отображения. Ниже порога можно сохранить черновик, но подготовка КП в PDF/Excel недоступна. В адресной программе проверяется общая сумма правильных строк. Бюджет брифа и короткой формы не может быть ниже минимума и не является итоговой ценой.

Цена не поднимается скрытой доплатой: увеличьте тираж или объедините изделия. Локальный импорт прайса ниже установленного минимума отклоняется.

## Стек и запуск

TypeScript, React 19, Next.js App Router API через Vinext, Tailwind 4, Shadcn/Radix, Zod, pdf-lib/fontkit, SheetJS. Node 22.13+, pnpm. Зависимости и lockfile сохранены.

~~~sh
pnpm install --frozen-lockfile
pnpm dev
node node_modules/typescript/bin/tsc --noEmit
node scripts/test-pricing.mjs
node scripts/test-production.mjs
node scripts/test-exports.mjs
node scripts/test-cabinet.mjs
node scripts/export-copy.mjs
pnpm build
~~~

test-pricing готовит локальные модули для последующих проверок. Результаты — в reports/. COPY.md содержит текст 130 маршрутов из исходных шаблонов; это не 129 браузерных тестов. Границы проверки — reports/QA.md и reports/CABINET_QA.md. Для локального кабинета после сборки примените миграцию D1 через Wrangler к preview-базе. Секреты задавайте в игнорируемом `.dev.vars`; пример имён — `.dev.vars.example`.

## Конфигурация

Все денежные тарифы — data/prices.json, без НДС. НДС 22% добавляется один раз. Дата версии обозначает редакцию конфигурации, а не новое исследование рыночных цен. priceApproval:false сохранён. Неизвестные ставки перечисляются отдельно.

Готовый баннер 330, 6×3: 3 395 ₽ без НДС / 4 141,90 ₽ с НДС за изделие. Печать того же размера по площади: 18 м² × 189 = 3 402 ₽ / 4 150,44 ₽. Разница между режимами сохранена. Пропуск А6, 50 000 шт. возвращает запрос без интерполяции.

data/recipes.json — рецепты и упаковка; data/regions.json — доступные округа и хабы; data/catalog.json — типы, исполнения, группы и прежние продукты; data/claims.json — утверждение обещаний. Zod проверяет схемы. Неутверждённые проценты монтажа и коэффициенты округов не применяются.

Упаковка на отправление: 2 м скотча и плёнка по площади изделия или 0,6 площади рулонного материала. Вес зависит от площади, количества и плотности. Газель — только для жёсткого изделия со стороной больше 2,5 м. Монтажные выезды округляются по каждому городу: до 3 адресов на выезд; склад — отдельный выезд. Доставка и неизвестные ставки согласуются отдельно.

## Адресная программа

Первый лист XLSX либо CSV, до 10 МБ и 10 000 строк. Колонки: город, адрес, ширина, высота, материал, количество, монтаж; вместо размеров — размер вида 6x3. Дополнительно: рецепт, толщина, плотность (г/м²), склад, высота буквы (см), широта, долгота. Материал — код из прайса или точное название.

Ошибочные строки исключаются из итога. Позиции одного города и адреса объединяются в отправление; монтажные расходники учитываются один раз на адрес. UI показывает первые 100 строк, Excel включает все. Координатный график использует только данные файла; геокодирования нет. Ссылка на Яндекс Карты открывается по действию пользователя.

## Дизайн и источники

Логотип, тёплая бумага, оранжевый и графитовый цвета, угловатая геометрия. Локальный DejaVu Sans с лицензией; Akrobat не приложен. Новая композиция материалов обозначена как концептуальная иллюстрация. Источники — data/asset-sources.json.

Маркетинг и применение навыков — MARKETING.md; дизайн — DESIGN.md; неподтверждённые данные — PLACEHOLDERS.md. Клиенты обезличены. Исторические показатели подписаны датой. Собственное производство, вымышленные отзывы и неподтверждённые гарантии не заявляются.

## Публикация

Sites использует существующий `.openai/hosting.json` и серверные привязки `DB` / `BUCKET`. Миграции `drizzle/*.sql` содержат только схему. Секреты находятся в runtime-конфигурации, а не в исходниках. Версия собирается из точного commit и обновляет прежний приватный URL. Права доступа не расширяются. Индексация закрыта до утверждения публичного запуска.

Исходники размещаются на GitHub отдельной папкой `projects/streetart`. GitHub Pages не выполняет серверный код кабинета: рабочему сайту требуются Worker, D1 и R2. Порядок переноса — [GITHUB.md](GITHUB.md).
