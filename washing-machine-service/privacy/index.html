Ваши данные и приватность.

Справочная информация о работе онлайн-помощников и формы обращения.

До открытия приёма заявок

Сейчас приём заявок закрыт. Калькуляторы работают в браузере и не отправляют введённые суммы и симптомы на сервер. Фотографии для распознавания кода обрабатываются на устройстве; для загрузки программы распознавания браузер обращается к поставщику программных файлов.

Форма обращения

Перед включением формы здесь должны быть указаны оператор, его адрес и контакт для обращений, цели, основания, сроки хранения и порядок удаления данных. Без этих сведений приём заявок не включается.

Сведения об операторе ещё не опубликованы.

Какие сведения нужны для записи

Имя, телефон, округ, сведения о технике, описание неисправности и выбранное время используются для обработки обращения. Фотография прикладывается добровольно. Не отправляйте паспортные данные, реквизиты карт, подписи и другие избыточные сведения.

Аналитика

Необязательная аналитика включается только после вашего согласия и только при подключённом счётчике. Выбор сохраняется в браузере. Вы можете изменить его кнопкой ниже.

Внешние ресурсы

Для отображения шрифта используются Google Fonts. При переходе по внешним ссылкам действуют правила соответствующего сайта. Секретные ключи и содержимое заявок не публикуются в репозитории.
